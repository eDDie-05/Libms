# Contributing to Library Management System

Thanks for taking an interest in this project.

## Project scope
Library Management System is a C console application. Please keep proposed changes aligned with the current scope and describe any change that expands it.

## Before making a change
1. Read the project README and understand the current structure.
2. Open an issue for a substantial change so the approach can be discussed.
3. Create a focused branch for your work.
4. Keep changes small and explain why they are needed.

## Development checks
Compile with `gcc lms.c -o lms` and run the resulting executable. Test each menu option using sample data.

## Pull requests
- Explain the problem and the proposed solution.
- List the files or features changed.
- Include the checks you ran and their results.
- Add screenshots for user-interface changes where useful.
- Do not commit passwords, API keys, tokens, private records, or generated build files.

## Reporting security concerns
Do not publish credentials, private data, or exploitable security details in a public issue. Contact the repository owner privately through GitHub instead.

All contributions should be respectful, constructive, and relevant to the project.
